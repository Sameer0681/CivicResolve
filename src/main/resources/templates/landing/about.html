FAQ

Frequently Asked Questions

Learn more about our architecture, SLAs, and data security.

How is CivicResolve architected under the hood?
CivicResolve uses a decoupled frontend/backend architecture. The citizen-facing frontend utilizes HTML5, Leaflet.js interactive maps, Web Speech API, and Bootstrap 5.3 with universal design tokens in common.css. It connects asynchronously via REST (fetch) to a Spring Boot backend backed by Hibernate JPA, Spring Security, and relational data storage.
How does the location pinning ensure field officer accuracy?
The wizard combines real device standing GPS with an interactive Leaflet point-and-click map pin. Field officers receive the exact latitude, longitude, and geocoded address, eliminating ambiguous reports like “near the big tree” and saving inspection hours.
Is citizen personal data protected?
Yes. Contact details are strictly guarded by Spring Security role-based authorization. Citizens can track grievances safely, and personal telephone numbers or emails are never published publicly on municipal bulletin boards.
