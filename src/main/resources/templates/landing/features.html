Capabilities

Available Capabilities

Server-rendered civic services designed to work without client-side JavaScript.

Feature 01
Complaint Classification

The configured AI provider can classify complaint text and suggest a service sector; citizens can select the sector directly in the form.

Feature 02
Written Complaint Form

Submit a title and description; AI assigns the service sector, and the map helps pinpoint the incident location.

Feature 03
Incident Location

Enter a nearby street, landmark, crossroad, or ward area to help identify where the issue occurred.

Feature 04
Department & Sector Mapping

Each official service sector is associated with its mapped department in the complaint record.

Feature 05
Server-Validated Submission

The server validates the complaint and returns a reference ID after the record is saved.

Feature 06
Reference-ID Tracking

Enter the reference ID to view the complaint’s current status, sector, and mapped department.

Feature 07
Response-Time Monitoring

Automated response-time monitoring is not currently configured.

Feature 08
Escalation Management

Automated complaint escalation is not currently configured.

Feature 09
Official Service Mapping

External municipal rosters and officer contact details are not configured.

Workflow

Complaint Lifecycle

From completing the form to looking up the current complaint status.

STEP 01
Describe the Issue

Enter a complaint title and a clear written description of the issue.

STEP 02
Choose a Service Sector

Select the official service sector that best fits the complaint.

STEP 03
Enter the Location

Provide a nearby street, landmark, crossroad, or ward area.

STEP 04
Server Validation

The server checks required fields and verifies the selected service sector.

STEP 05
Submission Receipt

After saving, the receipt displays the complaint reference ID and submitted details.

STEP 06
Track Current Status

Enter the reference ID on the Track page to see the current complaint status.

OPTIONAL
Sign In to Browse Your Complaints

Citizens can sign in to view their submitted complaints and open complaint details.

FAQ

Feature FAQs

Common questions about the available reporting and tracking flows.

How do I choose the complaint sector?
Select the official sector that best matches the issue. The selected sector determines the department mapping in your complaint.
Can I attach a photo or record my voice?
No. This version supports written complaint details only.
How can I check the current status?
Use the reference ID shown on your receipt in the Track a Complaint page.
